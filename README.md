# FinanceOS — Pulse OS

Financial intelligence platform for Arcturus Manufacturing GmbH.

## Features
- **Dashboard**: Real-time financial health KPIs, cash flow timeline, gross margin trends, and client AR concentrations.
- **Cash Flow**: Inflow vs. outflow vs. net cash position tracking with MoM change analysis.
- **Profit & Loss**: Multi-year revenue, gross profit, and EBIT performance statements.
- **Invoices & AR**: Aging buckets, client risk scoring, and statistical anomaly detection logs.
- **FX Intelligence**: Multi-currency exposure monitoring (EUR, INR, AED) with volatility and rate impact.
- **Scenario Simulator**: Real-time financial forecasting for headcount, COGS, opex, and revenue changes.
- **Data Portal**: Document ingestion for financial statements, bank statements, and master files.
- **Reports**: JSON-based downloadable health digests, cash statements, and aging logs.

## Tech Stack
- Next.js 13 (App Router)
- React 18
- Tailwind CSS
- Lucide React Icons
- Zustand State Management
- Recharts Chart Engine
